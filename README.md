# Essential Vending Website

A professional, mobile-responsive website for Essential Vending - a premium vending machine business founded by five ambitious high school entrepreneurs.

## Features

- **Modern Design**: Dark theme with professional business aesthetics
- **Mobile Responsive**: Fully optimized for all device sizes
- **Fast Loading**: Minimal JavaScript, optimized CSS
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Smooth Navigation**: Single-page application with smooth scrolling

## Sections

1. **Hero Section**: Eye-catching introduction with business goals
2. **Services**: Comprehensive vending solutions offered
3. **Products**: Three unique product categories (Medical OTC, Fragrances, Snacks & Drinks)
4. **About**: Team introduction and company story
5. **Contact**: Contact form and business information
6. **Footer**: Additional links and information

## Technology Stack

- **HTML5**: Semantic markup for better SEO
- **CSS3**: Modern styling with flexbox and grid
- **Minimal JavaScript**: Only for mobile menu and smooth scrolling
- **Google Fonts**: Inter font family for professional typography

## Setup Instructions

1. **Logo**: Replace `images/logo-placeholder.txt` with your actual logo file named `logo.png`
2. **Contact Form**: The contact form is currently frontend-only. You'll need to add backend processing for form submissions
3. **Email**: Update the email address in the contact section to your actual business email
4. **Content**: Customize any content to match your specific business needs

## File Structure

```
├── index.html          # Main HTML file
├── css/
│   └── style.css      # Main stylesheet
├── images/
│   └── logo-placeholder.txt  # Replace with logo.png

```

## Customization

The website is built with easy customization in mind:

- **Colors**: Main brand colors are defined in CSS variables at the top of `style.css`
- **Content**: All text content can be easily modified in `index.html`
- **Styling**: Modular CSS makes it easy to adjust specific sections
